# Changelog

All notable changes follow semantic versioning.

## 0.1.0 - 2026-08-25

### Added

- Codex plugin manifest and bounded project-status Skill.
- Five read-only MCP tools over a real stdio JSON-RPC server.
- Local Observer, Git, Verifier, goal, action, and decision projection.
- External user-data directory and anonymous project registry example.
- Localhost console, installation helpers, privacy scan, and CI gates.

### Boundaries

- Developer preview for macOS and one local user.
- No autonomous project mutation, pull-request delivery, deployment, or cloud synchronization.
